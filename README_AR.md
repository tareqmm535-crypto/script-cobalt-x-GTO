# كوبالت - النسخة المعربة (Cobalt - Arabic Localization)

**كوبالت (Cobalt)** هي أداة تطوير قوية لـ Robluox تعمل في وقت التشغيل (Runtime)،
وتستخدم لمراقبة وتحليل حركة الشبكة (Network Traffic) بين اللعبة والسيرفر.

تم تطوير الأداة بواسطة **deivid** و **upio**،
وهذا المشروع هو **إصدار عربي كامل** للواجهة مع تحسينات إضافية للدعم باللغة العربية.

---

## 🌟 المميزات الأساسية للسكربت

| الميزة | الوصف |
|---|---|
| **مراقبة الاستدعاءات** | تتبع جميع استدعاءات `RemoteEvent` و `RemoteFunction` و `BindableEvent` و `BindableFunction` |
| **تصنيف ذكي** | تقسيم الاستدعاءات إلى **صادر (Outgoing)** و **وارد (Incoming)** |
| **حظر وتجاهل** | حظر أو تجاهل أي Remote محدد بضغطة زر |
| **إعادة التشغيل (Replay)** | إعادة إرسال أي استدعاء تم تسجيله |
| **توليد أكواد** | نسخ كود Lua جاهز للاستدعاء أو الاعتراض (Hook) |
| **فك السكربتات** | فك ترجمة (Decompile) السكربتات الأصلية للعبة |
| **تصدير HTML** | تصدير جميع السجلات إلى ملف HTML للعرض خارج اللعبة |
| **نظام إضافات (Plugins)** | دعم كامل للإضافات الخارجية لتوسيع الوظائف |
| **حماية من مانعات الغش** | تجاوز مدمج لمانعات الغش الشائعة (Adonis, KR, etc.) |
| **بحث متقدم** | بحث سريع مع فلترة حسب الكلاس والاسم |
| **تسجيل ملفات** | حفظ السجلات في ملفات للرجوع إليها لاحقاً |
| **دعم الـ Actors** | تسجيل أحداث الـ Actors في Roblox |

## 🆕 الفرق بين هذه النسخة والنسخة الأصلية

### التحسينات العربية (Arabic Localization)

1. **واجهة مستخدم عربية بالكامل**
   - جميع أزرار الواجهة
   - جميع قوائم السياق (Context Menus)
   - جميع الإشعارات المنبثقة (Sonner Toasts)
   - جميع عناوين الأقسام والإعدادات
   - شاشة المعلومات التفصيلية (Info Modal)
   - نظام البحث والفلترة

2. **ترجمة احترافية**
   - نصوص قصيرة ومناسبة لحجم الأزرار والقوائم
   - توافق مع حركة الكتابة من اليمين لليسار (RTL-ready)
   - ترجمة دقيقة للمصطلحات التقنية مع الحفاظ على المعنى
   - استخدام المصطلحات المتداولة في مجتمع Roblox العربي

3. **ما لم يتم تغييره**
   - جميع دوال ومتغيرات الكود الأصلية (للحفاظ على التوافق)
   - المعرفات البرمجية (Keys) في جداول الإعدادات
   - أيقونات Lucide
   - نظام الإضافات (لضمان توافق الإضافات الخارجية)
   - هيكل البيانات وأنظمة الحفظ والتحميل

## 📥 التثبيت

### الطريقة الأولى - سطر واحد
انسخ والصق هذا السطر في منفذك (Executor):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/tareqmm535-crypto/script-cobalt-x-GTO/refs/heads/main/Cobalt.luau"))()
```

### الطريقة الثانية - تحميل الملف
1. قم بتحميل الملف `Cobalt.luau`
2. استخدم أي منفذ أو Executor يدعم تنفيذ سكربتات Luau
3. نفذ السكربت مباشرة في اللعبة
4. ستظهر الواجهة العربية بشكل تلقائي

> **ملاحظة:** يتطلب السكربت وجود بيئة `wax` (runtime) ليعمل بشكل صحيح.

## 🛠️ كيفية الاستخدام

- **زر البحث** 🔍 - ابحث عن أي Remote بالاسم
- **زر الإعدادات** ⚙️ - ضبط الإعدادات والتصفية
- **زر الإضافات** 📦 - إدارة الإضافات المثبتة
- **الضغط بالزر الأيمن** على أي Remote لإظهار قائمة السياق (حظر، تجاهل، نسخ كود، إلخ)
- **الضغط بالزر الأيمن** على أي استدعاء لإظهار خيارات إضافية
- **السحب** من حافة القائمة اليسرى لتغيير حجمها

## 📋 متطلبات التشغيل
